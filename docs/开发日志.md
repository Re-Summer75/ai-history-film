## 配乐 v3（audio/film_score.py）

- 一张贯穿全片的和弦表（CHART）；铺底连奏不断，段落之间只换色彩与亮度。
- 节奏层进出都有过渡：至少一小节渐强/渐弱，进段前筒鼓加花、反向镲、下一和弦倒放、军鼓滚奏；出段用镲片余音与延音盖住。
- 心跳贯穿第 1 幕（图灵 → 模仿游戏每小节一下 → 达特茅斯两下 → 感知机的底鼓），结尾心跳回来。
- 有意的静默只有：11.92 换气、24.0 磁带停转（冻结，八音盒慢慢问出主题）、175.72 屏息、315.9 的 0.1 s 空拍。
- 实测各段短时响度中位数，按目标（历史/对话/平静段落比律动低 4~8 dB）自动拉平。
- 提示音（ui_blip）音高吸附到 D 小调五声音阶，与配乐同调。

## 重编排（2026-09-28 第三轮）：按内容加长 · 镜头一镜到底 · 数据之城 · 配乐 v4

用户反馈："部分画面（尤其新加的内容）没看清就被切走了"——不是整体放慢，而是按内容重新编排。

**做法：各幕照旧用"原来的时间"写，登记完再按时间映射换算成成片时间**（web2/js/warp.js；acts/index.js 的 HOLDS）。
映射 = 整体平移 + 若干"停留窗口"：窗口只放在内容已经出完、停在那里等观众看清的地方（数字滚完、卡片落定、字幕出齐之后），
窗口两端平滑过渡；入场动画、镜头冲刺、重击都照原速。加长量都是半拍（0.5 s）的整数倍、每幕总量是整小节，画面重音仍在拍点上。
成片 352 s → 389 s。字幕可读时长用 `probe.py "await window.titleReport()"` 检查（出齐之后到开始退场，目标 ≥ 0.5 s + 字数/9）。

## 第五轮（2026-09-28）：循环段太吵、BGM 整体、转场空窗

- 实测：循环段吵的是配乐（音效比它低 15–30 dB）——满编律动上叠了两串十六分琶音。改成"蓄力"：铺底 + 1、3 拍底鼓 + 八分踩镲，
  只留一串跟转速加速的琶音，转快了底鼓变四拍、滤波打开，301 进操作电脑时律动才完整进来。
- 配乐：对话段加一条很轻的拨弦把四个时代连起来，各时代的签名音色收小（不再忽大忽小）；终端段用"敲代码"似的拨弦代替琶音，
  换段不再用镲片"重启"；数据之城的琶音从三十二分降到十六分，最后两秒用筒鼓加花推到冲出；各段电平起伏收窄、高潮抬高；
  混音里音乐比音效低 1.5 dB（原来 3 dB），让位最多 3 dB（原来 4 dB）。
- 画面空窗（用成片逐帧亮度扫出来的 ≥1 s 近黑片段）：计分板 → 循环（1.5 s，计分板不再先淡出，直接被卷进循环）、

  对话框光框、METR 坐标网格、"故事，才刚刚开始"都提前一点。保留的黑：片头、1950 的心跳光点、片尾收回心跳光点。
