# 程序化音效项目：给 Claude 的工作说明

本项目研究"让 Claude 用代码生成真实音效"。核心方法：**模拟物理过程，而不是画波形**；并用分析工具弥补 Claude 听不见的问题（看图 + 看指标 + 让用户盲听打分）。

## 环境

- Windows。Python 一律用 `.venv\Scripts\python.exe`（`python` 指向应用商店占位程序，不可用）。
- 命令行工具请用 PowerShell 运行（Git Bash 终端是 GBK 编码，中文输出会乱码）。
- 常用命令：
  - `.venv\Scripts\python.exe -W ignore -m sfx list`
  - `.venv\Scripts\python.exe -W ignore -m sfx render <配方> --seeds 0 1 2 --set 参数=值`
  - `.venv\Scripts\python.exe -W ignore -m sfx analyze <wav> --ref references\<参考录音>`
  - `.venv\Scripts\python.exe -W ignore -m sfx demo --clean`（重新生成全部试听样本和 `out/index.html`）


## 做一个新音效：必须走完的流程

1. **物理拆解**：发声的是什么物体或过程？什么材质、形状、尺寸？怎么被激发（撞击、摩擦、气流、液体、断裂）？
   在什么空间里、离听者多远？把声音拆成若干层，每层对应一个物理事件（参考 `door_slam` 的 7 层）。
2. **为每层选模型**：
   | 物理过程 | 用什么 |
   |---|---|
   | 撞击/敲击 | `modal`：`plate`/`bar`/`ring`/`bell`/`membrane`/`random_body` + `Hit(contact_ms, hardness)` |
   | 接触瞬间的"咔" | `modal.contact_noise` |
   | 摩擦（吱呀、嘎吱、刮擦） | `texture.stick_slip` → `filters.resonator_bank` 或 Body 的模态 |
   | 大量微小事件（雨、火、碎石、人群） | `texture.modulated_times`（泊松/Cox）+ `power_law` 幅度 + `scatter`（核要多变体） |
   | 气流（风、呼啸、爆炸轰鸣） | 噪声 + `filters.tv_filter`（参数由慢变控制曲线驱动） |
   | 液体 | `texture.bubble`（Minnaert，f0 = 3.26 / 半径米） |
   | 空间与距离 | `space.reverb`（房间）/ `space.outdoor`（户外，贴地声源设 `src_height=0`）/ `space.distance` |
3. **写配方**：放在 `sfx/recipes/<类别>.py`，用 `@recipe(tags=..., master=..., baseline=...)` 注册；新模块要加进 `recipes/__init__.py` 的 `MODULES`。
   所有随机数都从 `rng(seed)` 取（同一 seed 可复现）。环境声用 `master={"lufs": -20~-24}`，单次音效默认按真峰值 -1 dBTP 归一。
4. **渲染并检查**：每次渲染后**必须用 Read 打开分析图 PNG**，同时看 QC 提示。对照下面的诊断表修改。
5. **有参考录音时**：放进 `references/`，用 `analyze --ref` 并排比较频谱重心、衰减时间、频段能量和谱峰。
6. **让用户听**：更新试听页（`sfx gallery`），请用户打分。用户从试听页导出的评分 JSON 是最终依据，高于任何指标。

## 听感问题诊断表（征兆 → 常见原因 → 改法）

| 征兆（指标/听感） | 常见原因 | 改法 |
|---|---|---|
| 一团闷的低频，重心过低 | 输出的是"振动"不是"辐射声"；接触时间太长；模态只覆盖到低频 | 板状物体加一阶高通（辐射效率）；缩短 `contact_ms` 或加 `hardness`；增加模态数 |
| 像电子音、纯音 | 模态太少/整数倍泛音；没有噪声成分 | 用真实形状的模态比；加 `contact_noise`；对称物体用 `split` 产生拍频 |
| 纹理里有固定"音高" | 同一个带共振的核被重复几千次 | 核变体 ≥ 30 个，缩短核的余振 |
| 刺耳、嘶嘶 | 10 kHz 以上太多；非线性没过采样（混叠） | 空气吸收/低通；`saturate` 自带过采样，别自己写 tanh |
| 机械感 | 等间隔、等幅度 | `human_rhythm`、泊松过程、`power_law` 幅度 |
| 质感不对（像塑料/像金属） | 衰减率不对（材质感主要来自衰减，不是音高） | 调 `eta`/`alpha` 或换 `MATERIALS` |
| 悬在真空里 | 没有空间 | `reverb` / `outdoor`，湿声 -18~-9 dB |
| 小音箱上几乎听不到 | 能量大多在 60 Hz 以下 | 降低次低频层，补中频"质感"层（参考 `explosion` 的火球噼啪） |
| 长音死板 | 没有慢变起伏 | 用 `smooth_random` 调制音量、滤波频率、事件速率 |

QC 规则是启发式的。出现"误报"时先想想是否暴露了真实缺陷：例如"衰减段比峰值处更亮"曾经揭示了房间模型缺少低频驻波模态。

## 物理速查

- 模态衰减率 d = alpha + π·f·η（t60 = 6.91 / d）。η：金属 3e-4、玻璃 6e-4、陶瓷 2e-3、石 8e-3、木 0.02~0.035、塑料 0.035、纸板 0.08。
- 自由梁泛音比 1 : 2.756 : 5.404 : 8.933；环/杯 (k,0) 模态 ∝ k(k²-1)/√(k²+1)；钟 0.5, 1, 1.183, 1.506, 2 …
- 半正弦接触力在约 0.5/Tc 以上滚降、1.5/Tc 处有零点；力度越大接触越短（Tc ∝ v^-0.2）。
- 板在吻合频率以下辐射效率低（4 cm 木门约 470 Hz）。
- 空气吸收约 0.005·(f/1kHz)^1.5 dB/m；房间低频驻波 f = c·k/(2L)，Schroeder 频率 2000·√(RT/V)。

## 代码约定

- 48 kHz、float64；单声道 `(n,)`，立体声 `(n, 2)`。
- 混音：每层先 `normalize(x, 0)` 或按 RMS 归一，再用 dB 增益放进 `Mix`；母带处理只在 `master.finalize` 里做，配方里不要自己归一整体音量。
- 注释与文档用中文（用户是中文使用者）。
